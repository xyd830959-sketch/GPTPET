# 发布与申请证据清单

以下是本项目的审查准备步骤，不是 OpenAI 保证获批的条件。

- [ ] 检查分支、diff、版本、维护者信息和上游版权。
- [ ] 运行当前文件与全部本地 Git 历史的模式扫描，并人工检查图片、文档和归档。
- [ ] 确认角色、图标、语录及截图的预定分发用途有适当授权；未解决则暂停相关分发。
- [ ] 在专用目录执行全部适用自动测试，保留真实报告与失败记录。
- [ ] 完成兼容文档中的实机验收，标明未覆盖环境。
- [ ] 用打包脚本生成候选 ZIP 和 SHA256 清单，检查仅包含显式列出的项目文件。
- [ ] 将具体 diff、归档、素材范围及仍存在的历史问题交用户审阅。
- [ ] 取得用户对推送、公开、发布、发送或权限修改的分别确认。
- [ ] 经授权后才操作远端；检查远端提交号、可见性及实际 CI 结果。
- [ ] 维护真实问题与修复记录，按来源和区间整理 GPTPET 自己的使用情况。
- [ ] 根据当时官方申请要求核对身份、权限、维护证据及英文短答，再确认是否提交。

本地准备不能证明公开影响力、持续维护年限或一定入选。没有这些数据时应如实说明，不设定或编造最低 stars、最低天数、通过概率。
