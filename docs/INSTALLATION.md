# 安装、升级与退出

## 安装影响

安装前运行 `powershell.exe -NoProfile -File .\Install.ps1 -CheckOnly`。它读取安装信息和注册身份，不启动安装。正式安装会创建本地 `installation.json`、注册本地插件市场与额度插件、创建当前用户登录快捷方式和计划任务，并可能启动挂件。无需管理员权限。

当前数据沿用 `%LOCALAPPDATA%\GPTNiangUsage\state`，以兼容旧安装。GPTPET 不是与原 GPT-Niang 并行安装的第二个独立注册：安装器会拒绝占用其他目录的快捷方式或任务。应先确认原版已停用，并保留源码和配置备份。不要覆盖仍在运行的原版目录。

## 壁纸会话

默认不开壁纸。独立启动器只支持 `OpenAI.Codex` Store 包，使用 `%LOCALAPPDATA%\GPTNiangUsage\codex-wallpaper-profile`。默认从新配置开始；只有用户明确运行启动器并指定 `-ImportLegacyProfile` 时才复制现存 Dream Skin 配置，原目录保留。导入可能复制账号或会话数据，应由本人决定，不能作为测试、打包或 CI 的步骤。

已有独立配置继续使用，不自动迁移或覆盖。开启调试端口后不要在不受信任的共享电脑上使用该模式；完全退出客户端并使用普通入口重开可结束本次调试会话。

## 退出和停用

右键退出只停止本次挂件会话。`停用GPT娘.cmd` 会移除本工具的插件登记、计划任务和登录快捷方式，保留源码和个人数据。这涉及删除快捷方式和修改本机注册，执行前应确认具体路径与影响。停用不是删除所有用户数据。

## 回退

升级前在挂件停止后复制源码与配置到独立备份；保留旧版本与对应清单。壁纸异常时先使用“恢复默认背景”，或完全退出 Codex 再使用普通入口。需要恢复源码时先确认备份版本及配置相容性，再替换相应文件；不使用 `git reset --hard` 或清理用户数据来代替回退。
