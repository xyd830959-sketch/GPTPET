## 待实机验收

自动测试可以验证解析、状态、模拟调试连接和隔离 WPF 场景；不能替代实际桌面交互。发布候选版本时应记录：

- [ ] Windows、Codex、Node 版本和源码提交号。
- [ ] 全新安装与原版停用后的升级；其他安装的任务或快捷方式不被覆盖。
- [ ] 冷启动、普通模式和壁纸模式、关闭与恢复、退出后重新打开。
- [ ] 主页面、项目页、资料库、插件页和侧边聊天的壁纸与文字可读性。
- [ ] 不同缩放与多屏下的拖动、顶层顺序、额度显示与语录布局。
- [ ] 调试端口不可用、冲突、页面尚未出现时有明确提示。
- [ ] 脱敏截图和实测日期；无法验证的场景明确保留未验收状态。

这些复选项是候选版本验收表，不是已完成记录。旧实验文档中的成功记录只属于当时版本和环境。
