# 狐娘动画预览版

此目录保存当前狐娘版的独立源码与正在使用的成品资源。仓库根目录仍保留 GPTPET 1.2.6 正式版，原提交历史和来源声明保留。本目录代码沿用上游 MIT 许可；图像、视频与声音的范围另见 [素材说明](assets/ASSET-NOTICE.md)。

人物保持银白发、青蓝与象牙长裙、小狐耳和单尾。包含固定比例待机、短抱臂、蹲下抱耳、松手回位，以及菜单中的挥手、开心轻笑和哈欠。三个菜单声音使用用户选定的裁剪文件，分别为2.08、1.36和2.00秒。单击先显示额度，连续点击刷新不同台词；台词停留1.5秒。待机闲聊和本工作目录的回复完成提醒均可在菜单中关闭。

## 启动

需要 Windows 10/11、Windows PowerShell 5.1、Node.js 22+、已安装并登录的 Codex，以及单独准备的支持 `libvpx-vp9` 的 FFmpeg。源码不携带 FFmpeg 可执行文件，不需要 Python、H3、IndexTTS 或生成模型。[播放依赖说明](runtime/ffmpeg/README.md)

在本目录运行，替换示例解码器路径为你已有文件的位置：

```powershell
.\Start-FoxPet.ps1 -FfmpegPath 'C:\Tools\ffmpeg.exe' -CheckOnly
.\Start-FoxPet.ps1 -FfmpegPath 'C:\Tools\ffmpeg.exe' -Workspace (Get-Location).Path
```

`-CheckOnly` 检查依赖、透明视频解码器和引用素材，不写配置、不启动窗口。启动时在本目录生成不纳入 Git 的 `installation.json` 和 `state`；不会注册计划任务、开机启动或修改账号权限。已有正式版正在运行时，请先从其菜单退出，以免同时显示两个人物。退出本预览版可使用菜单，或运行 `Start-FoxPet.ps1 -Stop`。

`-Workspace` 指定回复完成提醒监测的工作目录。需要沿用自己的壁纸库时，显式传入 `-WallpaperDataDir`；该目录只供本地使用，不应上传到仓库。Node 和 Codex 不在 PATH 时，可分别传入 `-NodePath` 和 `-CodexPath`。播放或音效失败会保留可用画面与静态角色，状态仅写入自己的本地数据目录。

## 本轮代码整理

- 完成提醒监控最多保留128个会话文件、1024个去重标识，异常子目录不阻断其他文件。
- 每轮读日志有1MiB预算，并轮换起始文件，避免较早的大日志持续挤占后续会话。
- 保留明确完成事件、工作目录筛选、排除子任务、时间校验和启动不补报历史的行为；不保存对话正文。
- 删除未使用的最新帧接口、独立音效闲置计时器和重复的活跃会话集合。
- 独立入口不携带未调用的MCP控制器和计划任务启动入口；根目录正式版的这些能力仍保留。
- 只收录当前被引用的成品资源；参考录音、模型、生成环境、旧素材、运行状态、机器路径与验证截图不在源码分发范围。

回归检查通过仓库根目录的测试入口运行，见 [开发说明](../docs/DEVELOPMENT.md)。本地合成检查成功不代表远端 CI 已运行，也不代表声音自然度经过人工评价。
